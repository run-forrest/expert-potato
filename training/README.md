# 课程材料

`training/` 保存已布置课程和练习材料。文件存在不代表学习者已经完成；完成证据必须写入 `records/daily/`。

## 创建课程

- 使用 `weekN/dayNN_topic.md` 命名。
- 在批改上一学习日并更新 `records/current-state.md` 后再确定难度。
- 标准学习日包含旧错复测、可理解输入和短输出。
- 一次只提高文章长度、问题语言、输出长度、语法复杂度、听力速度或支持程度中的一个变量。
- 每个模块应能在约 10 分钟内独立完成，并有可计算的完成标准。

新课程使用 [课程模板](templates/lesson.md)。
