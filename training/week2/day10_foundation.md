### 5 个新词

1. **priority** — 优先事项  
   Collocation: set a priority  
   Example: I set one learning priority each day.

2. **realistic** — 现实可行的  
   Collocation: a realistic goal  
   Example: Reading one paragraph is a realistic goal.

3. **reduce** — 减少  
   Collocation: reduce stress  
   Example: A flexible plan can reduce study stress.

4. **organise** — 组织；安排  
   Collocation: organise your tasks  
   Example: I organise my tasks before I begin studying.

5. **consistent** — 持续稳定的  
   Collocation: consistent practice  
   Example: Consistent practice is more useful than one long lesson.

## B. Reading｜10 分钟

A useful study plan should be realistic as well as challenging. Some learners create a long list of daily tasks because they want to improve quickly. However, an unrealistic schedule often creates stress. When learners cannot finish everything, they may believe that they have failed and stop studying completely. A better approach is to set one priority for each short session. During a ten-minute break, this priority might be reviewing five words or reading one paragraph. Learners can organise more demanding activities, such as paragraph writing, for a longer period after work. The exact schedule may change from day to day, but the purpose of each activity should remain clear. This flexible system helps learners use their available time and maintain consistent practice. Over several months, completing realistic tasks regularly is more valuable than following an intensive plan for only a few days.

Questions:

1. Why do some learners create long daily task lists?
2. What may happen when a schedule is unrealistic?
3. What should learners set for each short session?
4. Which activity should learners organise for a longer period?
5. TRUE or FALSE: The exact schedule must remain the same every day.
6. 用一句英文概括文章主旨，并使用 `realistic` 或 `consistent`。

完成标准：前5题至少答对4题；英文主旨包含主语和动词。
