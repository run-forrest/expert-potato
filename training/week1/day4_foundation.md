# Day 4｜让句子更准确

今天仍是三个独立的 10 分钟模块。重点：`make` 句型、第三人称单数、名词复数和副词。

## A. Vocabulary and review｜10 分钟

### 先修正前三天的句子

1. Reading every day makes ______ easier to ______.
2. Regular practice is effective because it ______ learners ______ the rule.
3. I review ______ carefully so that I can write more ______.

### 5 个词

1. **mistake** — 错误  
   Collocation: make a mistake / correct a mistake  
   Example: I correct one repeated mistake each day.

2. **accurate** — 准确的  
   Collocation: an accurate sentence  
   Example: This sentence is clear and accurate.

3. **accurately** — 准确地  
   Collocation: write accurately  
   Example: I want to express my ideas accurately.

4. **explain** — 解释  
   Collocation: explain an idea clearly  
   Example: A simple example can explain the idea clearly.

5. **structure** — 结构  
   Collocation: sentence structure  
   Example: I check the structure of every sentence.

选择正确答案：

1. This is an **accurate / accurately** sentence.
2. She writes **accurate / accurately**.
3. Regular practice **make / makes** writing easier.
4. I review three **sentence / sentences**.

完成标准：4 题至少答对 3 题。

## B. Reading｜10 分钟

Editing does not mean changing every word in a paragraph. A learner should first check the basic structure of each sentence. Does it have a clear subject and a verb? If the subject is singular, does the verb need an extra “s”? The learner should then check nouns. A number greater than one usually requires a plural noun, such as “three sentences” or “two mistakes.” Finally, the learner can examine word forms. An adjective describes a noun, while an adverb usually describes an action. For example, an answer can be accurate, but a person answers accurately. This short editing process helps learners find repeated problems. It also makes their writing easier to understand without requiring difficult vocabulary.

Questions:

1. What should a learner check first?
2. When may an English verb need an extra “s”?
3. Why does the passage use “three sentences” instead of “three sentence”?
4. TRUE or FALSE: Difficult vocabulary is necessary for understandable writing.
5. 用一句中文概括文章主旨。

完成标准：答对至少 4 题。

## C. Sentence building｜10 分钟

完成三个句子：

1. I often make mistakes when ______.
2. Reviewing my sentences makes ______ easier to ______.
3. I check my sentence structure carefully because ______.

然后用 **because / so / but** 把其中两句连接起来。

完成标准：使用至少一个复数名词、一个第三人称单数动词和一个副词。把 A、B、C 的答案一起发给我；本练习不计正式分数。
