# Day 3｜形容词与副词

今天仍是三个独立的 10 分钟模块。重点：形容词描述名词或状态；副词描述动作。

## A. Word forms｜10 分钟

### Day 2 补写

1. Reading every day makes ______ easier to ______.
2. I review ______ every day so that I can ______ effectively.

### 五组词形

| 形容词 | 副词 | 示例 |
|---|---|---|
| easy | easily | This task is easy. / I can finish it easily. |
| effective | effectively | This method is effective. / It works effectively. |
| regular | regularly | I have a regular routine. / I study regularly. |
| careful | carefully | I am careful. / I read carefully. |
| clear | clearly | My idea is clear. / I explain it clearly. |

选择正确词形：

1. Short practice is **effective / effectively**.
2. It helps me learn **effective / effectively**.
3. I review new words **regular / regularly**.
4. This exercise is **easy / easily**.
5. I can understand it **easy / easily**.

完成标准：5 题至少答对 4 题。

## B. Reading｜10 分钟

Making mistakes is a normal part of learning English. Some learners avoid writing because they want every sentence to be perfect. This makes practice more difficult. A more effective method is to write a few sentences regularly and review them carefully. First, learners should check whether every sentence has a subject and a verb. Next, they should ask whether the meaning is clear. They do not need to correct every small problem at once. If they fix one repeated error, such as using an adjective instead of an adverb, their writing can gradually become more accurate. Short feedback also helps learners remember the rule more easily. The goal is not to produce perfect English today. It is to express one idea clearly and make fewer mistakes tomorrow.

Questions:

1. Why do some learners avoid writing?
2. What method does the passage recommend?
3. TRUE or FALSE: Learners should correct every small error at the same time.
4. 用一句中文概括文章主旨。

完成标准：答对至少 3 题。

## C. Sentence building｜10 分钟

完成三个句子：

1. Regular practice is effective because ______.
2. I review ______ carefully so that ______.
3. I want to express ______ clearly.

然后用 **and / but / because / so that** 连接其中两句。

完成标准：三个句子意思完整；正确使用至少两个副词。把 A、B、C 的答案一起发给我，本练习不计正式分数。
