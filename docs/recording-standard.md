# 学习记录规范

本规范确保学习证据可追踪、可比较，并适合保存在 GitHub。课程材料不是完成证据；实际答案和由答案生成的记录才是。

## 真相层级

发生冲突时，按以下顺序判断：

1. 最新的学习者实际作答或可靠转写。
2. 对应的 `records/daily/` 每日原子记录。
3. 最新 `records/weekly/` 周报。
4. `records/current-state.md` 当前快照。
5. `records/history/` 历史摘要。
6. `training/` 课程材料。

`records/mastery.md` 和 `records/error-bank.md` 必须能够追溯到每日记录中的证据。

2026-11-23 之前已经形成的记录作为历史证据原样保留，不要求为了新模板追溯改写；后续更正使用追加说明，不覆盖当时的实际作答。

## 目录与命名

| 内容 | 路径或命名 | 创建时机 |
|---|---|---|
| 学习者档案 | `records/learner-profile.md` | 背景或长期目标改变时更新 |
| 当前状态 | `records/current-state.md` | 每次批改闭环后更新 |
| 错误库 | `records/error-bank.md` | 新错误、复测或掌握状态变化时更新 |
| 掌握清单 | `records/mastery.md` | 有充分迁移证据时更新 |
| 每日记录 | `records/daily/YYYY-MM-DD-dayNN.md` | 收到实际答案后创建或更新 |
| 周报 | `records/weekly/weekNN.md` | 每 7 个完整学习日创建 |
| 里程碑检测 | `records/assessments/YYYY-MM-DD-dayNN-type.md` | 完成 Day 30/60/100 或正式检测后创建 |
| 课程 | `training/weekN/dayNN_topic.md` | 已确定下一课难度后创建 |

课程编号按已完成学习日推进，不因跨自然日跳号。反馈重写属于原学习日，除非它本身构成一套新的完整课程。

## 每日记录

每日记录使用 [模板](../records/templates/daily-record.md)，至少包含：

- 日期、学习日、状态、实际用时和课程链接；
- 各模块提交范围，明确缺失模块；
- 正确率、输出字数、句数或可验证完成度；
- 必要的学习者原句、错误 ID、修正方向和复测安排；
- 掌握变化和下一课只增加哪个难度变量。

状态只使用：

- `partial`：提交了部分模块，尚未达到完整学习日标准；
- `complete`：该学习日规定模块已经完成；
- `assessed`：完成的是里程碑或正式阶段检测。

未知用时写 `unknown`，不作估算。没有实际答案时，不创建每日完成记录。

## 错误生命周期

每个可复测问题使用稳定 ID，例如 `E011`。类别使用以下受控词表：

- `comprehension`：理解；
- `task-execution`：任务执行；
- `sentence-structure`：句子结构；
- `subject-verb`：主谓一致；
- `article-number`：冠词和复数；
- `word-form`：词形；
- `collocation`：搭配；
- `spelling`：拼写；
- `punctuation`：标点和句子边界。

状态定义：

| 状态 | 判定 |
|---|---|
| `active` | 新出现或最近一次变式复测错误 |
| `reviewing` | 已完成至少一次分隔复测，尚未完成三次 |
| `mastered` | `+1 / +3 / +7` 三次分隔变式复测正确，且至少一次来自自由输出或新场景 |

任一次复测错误，都从该学习日重新安排 `+1 / +3 / +7`。同一表面错误但根因不同可以使用不同 ID；同一根因的多个例子应继续使用原 ID。

## 掌握证据

证据强度从低到高为：

1. 选择或孤立填空正确；
2. 有提示的病句修改正确；
3. 无答案的新句正确；
4. 新话题自由输出正确；
5. 分隔复测后仍能自由使用。

只有第 5 级可以单独支持 `mastered`。阅读、听力和口语能力也必须由对应模态的任务证明，不能用写作表现代替。

## 周报与评估

周报使用 [模板](../records/templates/weekly-review.md)，只聚合本周期实际完成的学习日。必须列出：完成量、分项结果、高频错误、掌握变化和下一周唯一主要难度决策。

里程碑检测使用 [模板](../records/templates/milestone-assessment.md)。自编题、AI 生成题和自评应标明 `confidence: low` 或 `medium`；只有可靠标准化材料才能标记更高可信度。任何非官方短测都不能冒充 IELTS Band。

## 公开仓库规则

- 只保留支持学习判断所需的最小原句，不复制整篇答案到多个文件。
- 工作案例去除公司、客户、产品、域名、账号和内部数据。
- 外部文章只记录来源链接、必要短引和学习结论；不复制受版权保护的完整内容。
- 原始录音和下载材料默认不进入 Git；保留转写、时间戳和错误摘要。
- 修正历史记录时保留原证据，并追加 `correction` 说明；除非学习者明确要求，不删除既有学习证据。
